# Employee Data Analysis

## Project Overview

This project analyzes employee data to identify patterns and trends related to employee demographics, salary, performance, job satisfaction, work mode, and attrition.

The analysis was performed using Python and focuses on extracting meaningful business insights from the employee dataset.

## Objectives

* Analyze employee distribution across departments and job roles
* Examine salary patterns across departments and genders
* Analyze employee attrition and attrition rate
* Study the relationship between job satisfaction and attrition
* Analyze performance ratings
* Examine employee distribution by work mode
* Identify key business insights and recommendations

## Dataset

The dataset contains **1,500 employee records** and **16 columns**.

Key columns include:

* Employee ID
* Department
* Job Role
* Gender
* Age
* Education
* Location
* Hire Date
* Salary
* Performance Rating
* Job Satisfaction
* Employment Status
* Work Mode
* Manager
* Attrition

The project includes:

* Data loading and inspection

## Key Insights

* Total employees analyzed: **1,500**
* Overall attrition rate: **26.53%**
* Finance has the highest number of employees.
* Sales has the highest average salary among departments.
* Remote work mode has the highest number of employees.
* Job satisfaction level 3 has the highest attrition rate.
* The analysis highlights differences in employee distribution, salary, performance, satisfaction, and attrition across different employee groups.

## Visualizations

The project includes visualizations created using Matplotlib and Seaborn, including:

* Attrition by Department
* Attrition by Gender
* Performance Rating Distribution
* Average Salary by Department

## Business Recommendations

Based on the analysis, organizations can:

* Investigate the major factors contributing to employee attrition.
* Focus on departments with relatively higher attrition.
* Monitor employee satisfaction and engagement.
* Analyze performance and satisfaction together to identify areas for improvement.
* Use salary and employee distribution insights to support workforce planning.
* Develop strategies to improve employee retention.

## Conclusion

This project demonstrates the use of Python, Pandas, Matplotlib, and Seaborn to perform exploratory data analysis and generate meaningful business insights from employee data.

The analysis helps understand workforce patterns and supports data-driven decisions related to employee retention, compensation, performance, and workforce planning.
